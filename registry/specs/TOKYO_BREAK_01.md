# TOKYO_BREAK_01 — пробой токийского диапазона
Статья 24936: https://www.mql5.com/en/articles/24936 (From Evidence to Execution, Part 2).

## Важно про чистоту
Автор выводил пороги на GBPUSD M15 за январь 2025 – август 2026. Это пересекается с нашим закрытым экзаменом,
значит для этого правила экзамен не будет чистым. 2020–2024 для правила — данные вне подбора.
Заявление автора для сравнения: GBPUSD 2022–2024 — 107 сделок, PF 1,99; EURUSD 2019–2026 — PF 0,82.

## Тесты
- Основной: GBPUSD M15. Чувствительность: EURUSD M15 (оба инструмента есть у автора).

## Из статьи и кода автора
1. Диапазон: свечи M15, открывшиеся с 02:00 до 10:00 по серверному времени (без 10:00). Годен, если свечей >= 8,
   ширина R > 0 и ATR(14) > 0. ATR берётся на первой свече после окна.
2. Вчерашний максимум и минимум — предыдущий торговый день по серверному времени.
3. Пробой: закрытие выше верха + 0,05 ATR (вверх) или ниже низа − 0,05 ATR (вниз), не позже 48 свечей после окна.
   Пока есть позиция, пробои не отмечаются. Первый пробой стороны «расходует» её, даже если фильтры отказали.
4. Фильтр места: вверх (вчерашний максимум − верх диапазона) <= +50 пунктов; вниз (низ диапазона − вчерашний минимум) <= +50.
   Нижней границы нет.
5. Фильтр свечи: тело / (максимум − минимум) >= 0,80.
6. Не больше одной сделки на диапазон.
7. Стоп от границы диапазона: вверх — 0,60 R ниже верха; вниз — 1,50 R выше низа. Расстояние не меньше 0,5 ATR и 3 спредов.
8. Цель от закрытия пробойной свечи: вверх 0,85 R, вниз 0,30 R.
9. Вход отменяется, если цена входа уже за стопом или уже дошла до цели.
10. Сопровождение по каждой закрытой свече после входа (k = номер свечи сделки), выход по открытию следующей свечи:
    сначала «закрытие назад в диапазон» глубже 0,25 R; затем конец дня (свеча с временем открытия >= 21:45);
    затем k >= 32; затем при k >= 16 стоп подтягивается на 1,5 ATR от закрытия (только улучшая и не за рынком).
11. Размер позиции у автора: <= 2 свечей после окна 0,6; 3–6 — 1,0; 7–14 — 0,4; позже 0,6; продажи ещё ×0,6.

## Мои допущения
- Серверное время = UTC+2 зимой и UTC+3 во время летнего времени США (брокер автора не назван).
- Вход по открытию свечи сразу после пробойной (так описано в тексте; по порядку строк в коде мог бы быть на свечу позже).
- Спред для минимального стопа — спред пробойной свечи. Минимальная дистанция брокера (stops level) = 0.
- Если в одной свече достигнуты и стоп, и цель — считается стоп. Открытие за стопом — исполнение по открытию.
- Основной счёт тестера — в пунктах без весов размера. Результат с весами размера считается отдельно и на вердикт не влияет.

## Как судим (записано до прогона, 2026-11-26)
- История BAZA, UTC, цены Bid, только 2020–2024. Закрытый экзамен с 2025-01 не открывается.
- Считаются только проверочные окна проекта: июль 2020 – декабрь 2024 (AUDUSD с третьего окна).
- Издержки проекта: спред свечи + 7 USD комиссии за лот.
- «Прошло» = нетто > 0, PF >= 1,3, сделок >= 100.
- Дополнительно, для всех тестов с нетто > 0: 500 прогонов случайных входов (то же число сделок, те же стороны,
  то же время удержания и те же расстояния стопа и цели, случайные моменты). Считаем долю случайных не хуже правила.
- Никакие числа после прогона не подбираются. Любая переделка — новое правило с новым номером.
