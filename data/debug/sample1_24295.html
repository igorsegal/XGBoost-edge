Introduction

Effective data visualization is an essential part of analyzing trading strategies and financial markets. While MetaTrader 5 provides built-in charting capabilities, more specialized visualizations can help traders explore relationships, distributions, and patterns in market data. A Matplotlib-like plotting interface in MQL5 offers a practical way to create these visualizations while delegating the rendering process to Python.

In the previous article, we built the foundation of our Matplotlib integration by establishing the communication architecture between MQL5 and the Python backend. As a result, MQL5 applications can now use a Python-like Matplotlib syntax to construct figures and display Python-generated visualizations directly in the MetaTrader 5 terminal with minimal effort.

In this article, we build on that foundation by expanding the framework with a broader range of plotting and visualization techniques. We will implement additional chart types and their associated parameters, allowing MQL5 applications to produce richer and more informative visualizations while maintaining the familiar Matplotlib-style interface.

Through practical examples using trading and financial data, we demonstrate how these features can be combined into a consistent visualization workflow. The result is a more versatile Matplotlib-like API that allows MQL5 developers to explore and present data without having to implement the underlying rendering functionality themselves.


A Scatter Plot

A scatter plot displays individual observations as points on a two-dimensional coordinate system. Unlike a line plot where consecutive observations are connected, a scatter plot deliberately leaves the observations disconnected. This makes it useful when the relationship between two variables is more important than the sequence of observations.

In Matplotlib, a scatter plot can be created using the method Axes.scatter():

ax.scatter(x, y)

What makes scatter plots useful is that additional dimensions can be encoded into the points themselves. For example, the size of a marker can represent volume, its color can represent another numerical variable, and its shape can distinguish different categories.

When it comes to trading, scatter plots can be used for:

  • Correlation analysis —  to visually inspect the relationship between two instruments or indicators.
  • For clustering analysis — to visualize observations classified into different market regimes.
  • In detecting outliers as unusual observations often appear as isolated points.

    Let's use a scatter plot to display percentage returns for each bar against that bar's tick volume.

    #include <MatplotLib\pyplot.mqh>
CPyplot plt;
//+------------------------------------------------------------------+
//| Script program start function                                    |
//+------------------------------------------------------------------+
void OnStart()
  {
//--- Getting info from the terminal

   uint total_bars = 1000;
   vector close = vector::Zeros(total_bars), tv = vector::Zeros(total_bars);
   
   close.CopyRates(Symbol(), PERIOD_CURRENT, COPY_RATES_CLOSE, 1, total_bars+1); //closing prices
   tv.CopyRates(Symbol(), PERIOD_CURRENT, COPY_RATES_VOLUME_TICK, 1, total_bars); //tick volumes

//--- Calculating percentage changes

   vector pct_change = vector::Zeros(total_bars);
   for (ulong i=1; i<pct_change.Size(); i++)
    {
      double prev = close[i-1], curr = close[i];
      pct_change[i-1] = ((curr - prev) / prev) * 100.0;
    }
   
//--- pct change against tick volume scatter plot

   CFigure fig = plt.subplots();

   CAxes ax;
   ax.scatter(tv, pct_change, "dodgerblue");
   
   ax.set_title("% Change Against Tick volume - "+Symbol());
   ax.set_xlabel("Tick Volumes");
   ax.set_ylabel("% Change (close prices)");
   ax.grid();   
   
   fig.add_axes(ax); //Add the scatter plot Axes to a figure
   plt.show(fig); //display the entire figure
   DebugBreak();
}

    Results.

    Notice: The results produced by the examples in this article depend on the current chart symbol, timeframe, broker, and available account history. Therefore, the plots may differ from those shown in the article.

    Bar Plot

    This visualization technique is used to compare the magnitude of discrete or categorical values. Each observation is represented by a rectangular bar where the height of a bar represents its value.

    The categories are positioned along the x-axis, while their corresponding values are represented on the y-axis.

    Bar plots are useful in datasets that consist of discrete categories that need to be compared. See the example below where we display profits made on several instruments:

    #include <MatplotLib\pyplot.mqh>
CPyplot plt;
//+------------------------------------------------------------------+
//|                                                                  |
//+------------------------------------------------------------------+
input string matplotlib_style = "bmh";
//+------------------------------------------------------------------+
//| Script program start function                                    |
//+------------------------------------------------------------------+
void OnStart()
  {
//--- Setting a style to use for Matplotlib

   plt.style.use(matplotlib_style);

   string symbols[] = {"EURUSD", "XAUUSD", "USDCAD", "BTCUSD"};
   vector pl_vector = {120.5, -52.3, 43.1, 12.8};
   string colors[] = {    
                       "#2ecc71", //green
                       "#e74c3c", //red
                       "#2ecc71", //green
                       "#2ecc71"  //green
                     };

//---

   CFigure fig = plt.subplots(1, 1, 5, 4);
   CAxes ax;

   ax.bar(symbols, pl_vector, colors);

   ax.set_title("PL on the Account for Every Instrument");
   ax.set_xlabel("Symbols");
   ax.set_ylabel("PL");
   ax.grid(true);

   fig.add_axes(ax);
   plt.show(fig);
   DebugBreak();
  }

    A Histogram

    A histogram is used to visualize the distribution of numerical data. Unlike a regular bar chart, where each bar usually represents a distinct category, a histogram divides a continuous range of values into a series of intervals called bins; it then counts how many observations fall within each bin.

    For example, when analyzing the percentage change of a financial instrument, a histogram can show how frequently different ranges of returns occur. This makes it useful for identifying the center, spread, skewness, and shape of a return distribution, as well as detecting unusually large positive or negative movements.

    When it comes to trading, histograms can be used for:

    • Assessing return distributions by explaining how frequently different returns occur.
    • In drawdown analysis and more.

    For example:

    #include <MatplotLib\pyplot.mqh>
CPyplot plt;
//+------------------------------------------------------------------+
//|                                                                  |
//+------------------------------------------------------------------+
input string matplotlib_style = "bmh";
//+------------------------------------------------------------------+
//| Script program start function                                    |
//+------------------------------------------------------------------+
void OnStart()
  {
//--- Setting a style to use for Matplotlib

   plt.style.use(matplotlib_style);

   uint total_bars = 1000;
   vector close = vector::Zeros(total_bars), tv = vector::Zeros(total_bars);
   
   close.CopyRates(Symbol(), PERIOD_CURRENT, COPY_RATES_CLOSE, 1, total_bars+1); //closing prices

//--- Calculating percentage changes

   vector pct_change = vector::Zeros(total_bars);
   for (ulong i=1; i<pct_change.Size(); i++)
    {
      double prev = close[i-1], curr = close[i];
      pct_change[i-1] = ((curr - prev) / prev) * 100.0;
    }
    
//---

   CFigure fig = plt.subplots(1, 1, 5, 4);
   CAxes ax;
   
   int bins = 20;
   ax.hist(pct_change, bins, "gray");

   ax.set_title("Distribution of % change for closing prices on "+Symbol());
   ax.set_xlabel("% Change");
   ax.set_ylabel("Frequency");
   ax.grid(true);

   fig.add_axes(ax);
   plt.show(fig);
   DebugBreak();
  }

    Pie Chart

    A pie chart represents a collection of values as proportional slices of a circle. Each value determines the size of one wedge relative to the sum of all values.

    Below is how a fractional area of each wedge is calculated:

    When it comes to the trading space, pie charts are useful in visualizing data that represents parts of a whole, for example:

    • Visualizing trade distribution — showing the proportion of trades opened by either the user or an EA on different instruments or strategies.
    • Visualizing profit distribution — displaying how much each instrument contributes to the total profit/loss in the account

    As an example, let's display trade distribution in my demo account.

    Starting with collecting trade metrics from the terminal:

    //+------------------------------------------------------------------+
//|Returns the number of trades closed on a symbol from the first day|
//+------------------------------------------------------------------+
uint TradesBySymbol(string symbol, datetime start = 0)
  {
   uint total = 0;
   CDealInfo m_deal;

   if(HistorySelect(start, TimeCurrent()))
     {
      for(int i = HistoryDealsTotal() - 1; i >= 0; i--) //loop through all the deals
         if(m_deal.SelectByIndex(i))
            if(m_deal.Symbol() == symbol)
               if(m_deal.Entry() == DEAL_ENTRY_OUT) //A closed deal already
                  total++;
     }

   return total;
  }
//+------------------------------------------------------------------+
//| Assigns symbols that have trade history and the number of trades|
//| for every instrument in symbols[], and trades[] arrays           |
//| respectively                                                     |
//+------------------------------------------------------------------+
void TradingActivitySymbols(string &symbols[], uint &trades[])
  {
   int s_total = SymbolsTotal(false);
   uint found = 0;
   
   for(int i = 0; i < s_total; i++)
     {
      string name = SymbolName(i, false);
      uint trades_taken = TradesBySymbol(name);

      if(trades_taken == 0)
         continue;
      
      found++;
      
      ArrayResize(symbols, found);   
      ArrayResize(trades, found);
      
      symbols[found-1] = name;
      trades[found-1] = trades_taken;
     }
  }

    After obtaining the data (symbols and trades arrays), we pass them to the method CAxes::pie() for the creation of a pie chart. 

    A complete script:

    #include <MatplotLib\pyplot.mqh>
CPyplot plt;
#include <Trade\DealInfo.mqh>
//+------------------------------------------------------------------+
//|                                                                  |
//+------------------------------------------------------------------+
input string matplotlib_style = "bmh";
//+------------------------------------------------------------------+
//| Script program start function                                    |
//+------------------------------------------------------------------+
void OnStart()
  {
//--- Setting a style to use for Matplotlib

   plt.style.use(matplotlib_style);
   
   string symbols[];
   uint trades[];
   
   TradingActivitySymbols(symbols, trades);
   
   vector trades_vector = {};
   trades_vector.Assign(trades); //Assign trades array to a vector 

//---

   CFigure fig = plt.subplots(1, 1, 7, 5);
   CAxes ax;
   
   ax.pie(trades_vector, symbols, false, "%1.1f%%");
   
   ax.set_title("Trading activity on My Account");
   
   fig.add_axes(ax);
   plt.show(fig);
   DebugBreak();
  }

    Hexbin Plot

    A hexbin plot is a two-dimensional visualization technique used to show the distribution and concentration of observations. Instead of plotting every observation as an individual point, the plotting area is divided into a grid of hexagonal cells.

    Observations falling inside the same hexagon are grouped, and the color of each hexagon represents the number of observations or an aggregated value associated with those observations.

    Hexbin plots are useful when working with large datasets where a conventional scatter plot can become overcrowded for visualizing data points. For example, a scatter plot of thousands of returns visualized against their tick volume may produce a dense cloud of overlapping points. Hexbin replaces those individual points with colored hexagons, making areas of high and low observation density much easier to identify.

    #include <MatplotLib\pyplot.mqh>
CPyplot plt;
//+------------------------------------------------------------------+
//|                                                                  |
//+------------------------------------------------------------------+
input string matplotlib_style = "bmh";
input group "Figure";
input uint WIDTH = 7;
input uint HEIGHT = 5;
//+------------------------------------------------------------------+
//| Script program start function                                    |
//+------------------------------------------------------------------+
void OnStart()
  {
//--- Setting a style to use for Matplotlib

   plt.style.use(matplotlib_style);

//---

   uint total_bars = 1000;
   vector close = vector::Zeros(total_bars), tv = vector::Zeros(total_bars);
   
   vector tick_volume = {};
   close.CopyRates(Symbol(), PERIOD_CURRENT, COPY_RATES_CLOSE, 1, total_bars+1); //closing prices
   tick_volume.CopyRates(Symbol(), PERIOD_CURRENT, COPY_RATES_VOLUME_TICK, 1, total_bars);
//--- Calculating percentage changes

   vector pct_change = vector::Zeros(total_bars);
   for (ulong i=1; i<pct_change.Size(); i++)
    {
      double prev = close[i-1], curr = close[i];
      pct_change[i-1] = ((curr - prev) / prev) * 100.0;
    }
    
//---

   CFigure fig = plt.subplots(1, 1, WIDTH, HEIGHT);
   CAxes ax;
   
   ax.hexbin(tick_volume, pct_change, vector::Zeros(0), vector::Zeros(0), 30, "log", "inferno");
   
   ax.set_title("% Returns Vs Volume");
   ax.set_ylabel("% Returns");
   ax.set_xlabel("Volume");
   
   ax.colorbar("counts");
   
   fig.add_axes(ax);
   
   plt.show(fig);
   DebugBreak();
  }

    Multiple Plots on a Single Axes

    A Matplotlib Axes object can contain multiple plots, allowing several data series to be visualized within the same coordinate system. Each series can have its own data, plot type, color, and label while still sharing the same X/Y axes, limits, grid, title, and other Axes-level properties.

    See the Python example below where we create a plot that contains two line plots and one scatter plot:

    fig, ax = plt.subplots(figsize=(6, 4))

ax.plot([1, 2, 3], [4, 5, 6], color='blue', label='Line Plot')
ax.plot([3, 2, 1], [4, 5, 6], color='red', label='Another Line Plot')
ax.scatter([1, 2, 3], [3, 8, 7], color='green', label='Scatter Plot')

ax.set_title("Multiple Plots on One Axes")
ax.set_xlabel("X Values")
ax.set_ylabel("Y Values")

    In Matplotlib, every time you call a method for creating a plot using the same Axes, a new plot is added to the mix regardless of its kind or instructions.

    The project does not yet support these composite plots. To support them, the framework must dynamically create a new plot object for each call (scatter, plot, barh, etc.).

    So, we need to dynamically add plots on top of each other (in a single Axes object). However, this raises a concern because each plot is unique, with different parameters and configurations. At the moment, we don't have a single/unified object for every plot; each plot (Axis) has its own data class.

    Working With Subplots

    Apart from having multiple plots in a single Axes; a single figure can contain multiple Axes as well.


    Suppose you want to have two plots (Axes) on a single figure (a line and a bar plot).

    In Matplotlib-Python, below lines of code accomplishes that: 

    import matplotlib.pyplot as plt

# Create 1 row, 2 columns of subplots
fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(7, 4))

# Plot on the first subplot
ax1.plot([1, 2, 3], [4, 5, 6], color='blue')
ax1.set_title('First Plot')

# Plot on the second subplot
ax2.bar([1, 2, 3], [6, 5, 4], color='green')
ax2.set_title('Second Plot')

plt.tight_layout()  # Fixes overlapping spacing
plt.show()

    The important part here is.

    fig, (ax1, ax2) = plt.subplots(1, 2)

    According to the docs.

    matplotlib.pyplot.subplots(nrows=1, ncols=1, *, sharex=False, sharey=False, squeeze=True, width_ratios=None, height_ratios=None, subplot_kw=None, gridspec_kw=None, **fig_kw)[source]

    Create a figure and a set of subplots.

    This utility wrapper makes it convenient to create common layouts of subplots, including the enclosing figure object, in a single call.

    The first two arguments specify the layout.

    1. Number of rows
    2. Number of columns

    Therefore, Matplotlib creates a Figure containing two Axes in the same row (1) but separate columns (2).

    Notice that ax1 and ax2 are independent Axes objects. Each one can have its own plot attributes, i.e., plot type, title, labels, grid, limits, and other properties.

    The figure only acts as a container that holds both Axes, as discussed in a previous article.

    A figure = the overall drawing surface.

    Axes = an individual plotting area inside that Figure.

    The method plt.tight_layour()  adjusts the spacing around the Axes so that titles, labels, and other elements do not unnecessarily overlap.

    To get the same capability in our MQL5 project, we have to make a few tweaks to the Figure class (CFigure), Axes class (CAxes), and inside the show() method.

    Just like matplotlib.style.use, the method CStyle::use() is responsible for setting a stylesheet to be used for Matplotlib.

    In the backend, we create a route that receives stylesheet instructions and applies a specified style to a matplotlib.pyplot object.

    import matplotlib.pyplot as plt


@app.route("/set-style", methods=["POST"])
def set_style():
    """Sets the style for the matplotlib plots.

    Returns:
        jsonify: A JSON response indicating success or failure.
    """

    data = request.get_json(silent=True)

    if not data:
        return jsonify({"error": "No JSON data provided"}), 400

    style = data.get("style")

    if style is None:
        return jsonify({"error": "No style specified"}), 400

    try:
        # Reset all rcParams to Matplotlib defaults
        plt.rcdefaults()

        # Apply the requested style
        plt.style.use(style)

    except OSError as e:
        return (
            jsonify({"error": f"Invalid Matplotlib style: {style}", "details": str(e)}),
            400,
        )

    return jsonify({"message": f"Style set to {style}"}), 200
